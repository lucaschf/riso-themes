# Changelog

## 1.1.0

- Options menu: *Theme · this project* and *Theme · all projects*, one ink picker
  with live preview; *Follow all projects* removes a project's own theme.
- Status bar shows a folder icon when the project has its own theme.
- *Bracket pair guides* row cycles `editor.guides.bracketPairs`.
- Leftover bracket / indent-guide colors of themes that no longer exist are removed.

## 1.0.0

- Eight inks — Touge, Green, Blue, Purple, Grey, Orange, Teal, Mustard — each with
  a Dimmed variant tinted with its own ink.
- Rainbow / duotone brackets and indent guides.
- Color by name for parameters, locals, attributes, constants and types.
- Per-project themes and the **Riso: Options…** menu.
