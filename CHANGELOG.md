# Changelog

## Unreleased

- README rewritten: screenshots of every ink, the three papers, the duotone and
  color by name; install steps, language support, a full settings and commands
  reference, and an FAQ.

## 1.2.0

- Three new inks from the risograph catalogue: **Pink** (fluorescent),
  **Federal Blue** and **Sunflower**.
- **Pink × Blue**: a duotone printed with two inks and their purple overprint.
- **Paper**: every theme also comes light, ink on warm cream stock.
  *Background* in the options menu picks Normal, Dimmed or Paper.
- Color by name uses each paper's own set, deep inks on the light one.
- The build audits the contrast of every text color on every paper.

## 1.1.0

- Options menu: *Theme · this project* and *Theme · all projects*, one ink picker
  with live preview; *Follow all projects* removes a project's own theme.
- Status bar shows a folder icon when the project has its own theme.
- *Bracket pair guides* row cycles `editor.guides.bracketPairs`.
- Leftover bracket / indent-guide colors of themes that no longer exist are removed.

## 1.0.0

- Eight inks — Touge, Green, Blue, Purple, Grey, Orange, Teal, Mustard — each with
  a Dimmed variant tinted with its own ink.
- Rainbow / duotone brackets and indent guides.
- Color by name for parameters, locals, attributes, constants and types.
- Per-project themes and the **Riso: Options…** menu.
